Política de Privacidade

MasterPalm · Última atualização: fevereiro de 2025

Esta Política de Privacidade descreve como o aplicativo MasterPalm coleta, usa e protege suas informações, em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018).

1. Dados que coletamos

O MasterPalm coleta os seguintes tipos de dados para prestar o serviço de gestão de loja:

  • Dados de conta: e-mail e senha (criptografados) para autenticação.
  • Dados de clientes: nome, telefone, e-mail, endereço, CEP, cidade e foto de perfil (quando cadastrados pelo usuário).
  • Dados de vendas e pedidos: produtos vendidos, valores, formas de pagamento, datas e histórico de compras.
  • Dados de estoque e catálogo: produtos, preços, quantidades e imagens.
  • Dados de contatos: apenas quando o usuário opta por importar contatos do dispositivo (para cadastro de clientes via WhatsApp).
  • Dados de uso: informações de uso do app para melhorias e análise de erros (Firebase Analytics e Crashlytics).

2. Finalidade do uso dos dados

Utilizamos os dados exclusivamente para:

  • Prestar o serviço de gestão de loja (vendas, clientes, estoque, catálogo).
  • Processar pagamentos (via gateways como Mercado Pago, PagSeguro e outros configurados pelo usuário).
  • Sincronizar dados entre dispositivos e na nuvem (Firebase).
  • Enviar notificações relevantes ao uso do app.
  • Melhorar a estabilidade e a experiência do usuário.

3. Base legal (LGPD)

O tratamento dos dados baseia-se em:

  • Execução de contrato: para fornecer o serviço contratado.
  • Legítimo interesse: para melhorias técnicas e segurança.
  • Consentimento: quando aplicável (ex.: importação de contatos).

4. Compartilhamento de dados

Os dados podem ser compartilhados apenas com:

  • Firebase (Google): armazenamento, autenticação e análise, conforme os termos do Google.
  • Provedores de pagamento: Mercado Pago, PagSeguro, Ton, InfinitePay e outros configurados pelo usuário, para processamento de transações.
  • Provedores de frete: Melhor Envio, Frenet e similares, quando o usuário configura integração.

Não vendemos nem alugamos seus dados a terceiros.

5. Segurança

Adotamos medidas técnicas e organizacionais para proteger os dados, incluindo criptografia em trânsito (HTTPS), autenticação segura e controle de acesso. Os dados são armazenados em servidores do Firebase (Google Cloud), em conformidade com padrões de segurança.

6. Seus direitos (LGPD)

Você tem direito a:

  • Confirmar a existência de tratamento de dados.
  • Acessar seus dados.
  • Corrigir dados incompletos ou desatualizados.
  • Solicitar a anonimização, bloqueio ou eliminação de dados desnecessários.
  • Revogar o consentimento, quando aplicável.

Para exercer esses direitos, entre em contato conosco pelo e-mail ou canal de suporte indicado no aplicativo.

7. Retenção de dados

Mantemos os dados enquanto sua conta estiver ativa e o serviço for utilizado. Após o cancelamento, os dados podem ser mantidos pelo período necessário para cumprimento de obrigações legais ou resolução de disputas.

8. Crianças

O MasterPalm não é destinado a menores de 18 anos. Não coletamos intencionalmente dados de crianças.

9. Alterações

Podemos atualizar esta política periodicamente. Alterações relevantes serão comunicadas por meio do aplicativo ou por e-mail. O uso continuado do app após as alterações constitui aceitação da nova versão.

10. Contato

Para dúvidas ou solicitações relacionadas a esta política ou aos seus dados pessoais, entre em contato:

  • Site: mastepalm.com.br
  • E-mail: contato@mastepalm.com.br (ou o e-mail de suporte exibido no app)
