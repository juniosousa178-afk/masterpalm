# P0 — firebase-admin ESM Auth hotfix (sendEmail + enviarEmailVerificacao)

DECISION=MASTERPALM_FIREBASE_AUTH_ESM_P0_FIXED_READY_FOR_SMTP_V4_TEST

## Root cause

`functions/index.js` is ESM and imports `import * as admin from "firebase-admin"`. With
firebase-admin 13.6.0 the ESM namespace only exposes `default`, so `admin.auth` is `undefined`.

- `enviarEmailVerificacao`: `admin.auth().generateEmailVerificationLink(...)` threw
  `TypeError: admin.auth is not a function` before SMTP (HTTP 500; pre-existing since at least
  2026-09-14, independent of the SMTP secret version).
- `sendEmail`: `verifyIdToken: (t) => admin.auth().verifyIdToken(t)` threw the same TypeError,
  swallowed by the contract (`catch → uid=""`) ⇒ every valid ID token got 401.

Earlier unit tests injected a fake `verifyIdToken`, so they could not detect it.

## Fix (minimal)

`import { getAuth } from "firebase-admin/auth";` plus, only in the two target functions,
`getAuth().verifyIdToken(token)` and `getAuth().generateEmailVerificationLink(emailNorm)`.
No contract, guard, recipient, rate-limit, idempotency, transport or response change.
